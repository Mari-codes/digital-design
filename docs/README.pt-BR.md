# Digital Design Agency

## Leia em outros idiomas
- [English](../README.md)

Este projeto é uma **landing page de agência de branding** construída com tecnologias modernas. Ele oferece **temas claro e escuro**, design responsivo e arquitetura baseada em componentes.

## Tecnologias usadas

- **React**
- **Vite**
- **SASS**
- **CSS Modules**
- **Metodologia BEM**

## Funcionalidades

- **Tema claro e escuro:** O usuário alterna entre temas com o botão de troca.
- **Design responsivo:** Funciona em desktop e dispositivos móveis.
- **Baseado em componentes:** Cada seção (Header, BannerSection, WorkExperienceSection, Home) é modular e reutilizável.
- **Variáveis e tokens de CSS:** Cores, fontes e espaçamento usam tokens e variáveis de tema para manter padrão.

## Como executar

1. Clonar o repositório:

```bash
git clone <your-repo-url>
cd <project-folder>
```

2. Instalar dependências:

```bash
npm install
```

3. Iniciar o servidor de desenvolvimento:

```bash
npm run dev
```
